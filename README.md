# Anna Vina Alquiza — Portfolio

A responsive pastel-lavender personal portfolio for Anna Vina Alquiza, Customer Support / General Virtual Assistant.

## Files

- `index.html` — portfolio structure/content
- `style.css` — responsive design, pastel lavender theme, cards, bubbles and animations
- `script.js` — mobile navigation and scroll-reveal animations
- `assets/anna-vina.jpg` — professional photo

## Add the resume

Place Anna's PDF resume in:

`assets/anna-vina-resume.pdf`

The "Download Resume" button is already connected to that filename.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files while keeping the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The site will then be available through the GitHub Pages URL.
